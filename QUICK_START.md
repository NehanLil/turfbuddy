# 🚀 Quick Start - Turf Mobile App

## Get Running in 3 Steps

### 1️⃣ Navigate to the app
```bash
cd mobile2
```

### 2️⃣ Start the server
```bash
npm start
```

### 3️⃣ Open on your device
- **Download** Expo Go app from App Store or Play Store
- **Scan** the QR code shown in terminal
- **Wait** for app to load

## That's It! 🎉

Your app is now running and connected to the same database as your web app.

## What You Can Do

✅ Create an account or sign in  
✅ Browse available game plans  
✅ Create new game plans  
✅ Send join requests
